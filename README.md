# Сбер.Проще — автономный MVP

Локальный пилот сценария «запрос → три предложения → выбор → демо-оплата → чек» по материалам презентации команды 14.

## Что работает

- текстовый и демонстрационный голосовой ввод;
- светлая и тёмная темы с сохранением выбора;
- форма поиска по 36 мок-рейсам: маршрут, дата и 1–4 пассажира;
- локальный разбор запросов по трём сценариям: авиабилеты, ужин, заправка;
- три предложения от мок-партнёров с учётом бюджета;
- тестовый кошелёк с пополнением, проверкой остатка и списанием при покупке;
- демонстрационное подтверждение оплаты без реальных денег;
- локальные чеки и история операций в `localStorage`;
- список мок-партнёров и описание пилота;
- адаптивный интерфейс для компьютера и телефона.

Приложение не выполняет сетевых запросов и не требует API-ключей. Все данные находятся в `src/mock-engine.js` и в локальном хранилище браузера.

## Запуск

Требуется Node.js 20 или новее.

```powershell
cd C:\Users\user\IdeaProjects\sber-prosche-pilot
npm start
```

Откройте `http://127.0.0.1:4173`.

## Тесты

```powershell
npm test
```

Тесты проверяют определение сценария, извлечение бюджета, выдачу предложений и создание демонстрационного чека.
